# Portfolio Project Instructions

## Working Style

- Do not ask the user to perform tasks that you can complete yourself. Execute those tasks independently.
- Start the website server yourself, inspect the site in a browser, and test multiple viewport sizes before reporting only the results.
- Use Phosphor Icons for interface icons.
- Never use the Sites skill for design work.

## Product Requirements

- Build the website with Next.js.
- Create a personal landing page for a scientist or engineer with six years of research or industry experience.
- Serve researchers, potential collaborators, hiring managers, and industry partners.
- Make **Get in Touch** the primary visitor action.
- Include Hero, About, a 12-project grid, Expertise, Selected Achievements, Contact, and Footer sections.
- Every project must provide fields for the problem, methods, individual contribution, and outcomes.
- The contact form must include name, email, organization, inquiry type, and message.

## Layout and Content

- Design for a 1920px-wide viewport with a maximum 1280px content container and 80px horizontal desktop padding.
- Reduce padding responsively for tablet and mobile layouts.
- Avoid excessively large type and repetitive two-column compositions.
- Do not use emojis.
- Do not invent publications, credentials, project results, affiliations, or other biographical claims.
- Use clearly labeled placeholders or neutral draft copy whenever verified portfolio facts are unavailable.
